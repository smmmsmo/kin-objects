# KIN Objects — Good Things, Kept Close

A serene e-commerce experience inspired by Nordic and Japanese wabi-sabi minimalism, featuring everyday sterling silver jewelry, keepsake lockets, and clothbound paper goods.

## Key Features
- **Still-Life Art Direction**: Tactile natural lighting and photography.
- **Holistic Curation**: Genderless fine jewelry alongside desk goods and clothbound notebooks.
- **Bag Drawer**: Live shipping progress bar and minimalist cart slideover.

## Tech Stack
- **React 19**
- **Vite 7**
- **Tailwind CSS v4**
- **Vanilla Motion**

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Deployment

### Vercel
Import the repository into [Vercel](https://vercel.com). Vercel detects Vite automatically (Build command: `npm run build`, Output directory: `dist`).

### Netlify
Connect this repository to [Netlify](https://netlify.com) or run `npx netlify deploy --prod`.

### GitHub Pages
An automated GitHub Actions workflow is provided in `.github/workflows/deploy.yml`. Go to **Settings → Pages → Source: GitHub Actions**.
